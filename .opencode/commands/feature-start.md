Inicia la feature `$ARGUMENTS`.

1. Lee `AGENTS.md` y `docs/04-features/README.md`.
2. Localiza `docs/04-features/$ARGUMENTS-*/spec.md`.
3. Comprueba dependencias, estado y Definition of Ready.
4. Resume: objetivo, alcance, contratos, archivos y tests.
5. Propón un plan de pasos pequeño.
6. **Espera confirmación.** No edites archivos todavía.
7. Si falta una decisión, para y pregunta.
