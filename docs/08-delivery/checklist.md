# Checklist de entrega

## Producto

- [ ] Registro, login, logout y sesión persistente.
- [ ] Círculos, álbumes e invitaciones.
- [ ] Subida desde móvil y escritorio.
- [ ] Galería, visor, metadatos y etiquetas.
- [ ] Descarga individual, selección y álbum.
- [ ] Perfil, tema y permisos.
- [ ] Subidas globales y actividad.
- [ ] Ayuda, FAQ y Privacidad.
- [ ] PWA instalable.

## Calidad

- [ ] Tests unitarios, API, componentes y E2E.
- [ ] Casos negativos de acceso.
- [ ] axe sin errores críticos.
- [ ] Teclado y lector de pantalla.
- [ ] Responsive 320–1440.
- [ ] Claro y oscuro.
- [ ] Sin errores de consola/hidratación.
- [ ] Lighthouse razonable.
- [ ] Seguridad revisada.

## Documentación

- [ ] README con instalación y scripts.
- [ ] ADRs.
- [ ] OpenAPI.
- [ ] Diagrama de entidades.
- [ ] Bitácora de IA.
- [ ] Mapa del temario con evidencias.
- [ ] Limitaciones.
- [ ] Guía de demo y defensa.

## Entrega

- [ ] Seed demo.
- [ ] Credenciales demo.
- [ ] Vídeo de respaldo.
- [ ] Diapositivas.
- [ ] Flujo probado con dos usuarios y dos círculos.
- [ ] App instalada en Android.
- [ ] URL o demo local.
- [ ] Commit final revisado.
